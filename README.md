# Sales Analysis Project

## Overview
This project analyzes sales data using Power BI to generate meaningful business insights.

## Tools Used
- Power BI
- SQL
- Microsoft Excel

## Key Features
- Sales and profit analysis
- KPI cards
- Interactive charts and slicers
- Data visualization
